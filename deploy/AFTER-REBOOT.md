# Что делать после перезагрузки сервера

Короткий ответ: **ничего не делать, одну команду проверить**. Всё поднимается
само — служба бота, Cloudflare-туннель, Tailscale, правила маршрутизации, крон.

## Одна команда

```bash
ssh -p 3033 ignor@172.30.1.93 "bash /opt/basketball-bot/deploy/healthcheck.sh"
```

Здоровый ответ выглядит так:

```
▶️  Бот
  ✅ служба работает (с Thu 2026-08-06 13:53:48 UTC)
▶️  Фэнтези-API (Mini App)
  ✅ слушает порт 8081, отвечает (401)
▶️  Двери снаружи
  ✅ Cloudflare-туннель (основная дверь) активен
  ✅ Tailscale поднят (запасная дверь)
▶️  Маршрутизация
  ✅ правила 38–42 на месте
▶️  Расписание
  ✅ крон на месте (18 заданий)
▶️  Данные
  ✅ база читается, строк статистики: 44154

Итог: всё на месте, вмешательства не требуется.
```

`401` у API — **здоровый** ответ: без подписи Telegram внутрь не пускают.

Проверка ничего не чинит и ничего не пишет. Пароля не просит: все команды либо
не требуют прав, либо совпадают со строками, разрешёнными в sudoers.

## Если что-то красное

Возле каждого ❌ написана команда, которая его чинит. По порядку вероятности:

| Что | Команда |
|---|---|
| Бот не работает | `sudo systemctl start basketball-bot` |
| API не слушает 8081 | `sudo systemctl restart basketball-bot` |
| Туннель не активен | `sudo systemctl start cloudflared-api` |
| Нет правил маршрутизации | `sudo /usr/local/sbin/basketball-bot-telegram-route.sh` |
| Нет крона | `sudo cp /opt/basketball-bot/deploy/basketball-cron /etc/cron.d/basketball-bot` |

После любой починки — прогнать проверку ещё раз.

## Чего ждать в первые минуты

Это нормально и лечится временем, а не руками:

* **Первые 30–60 секунд** — бот отвечает, но фэнтези-пул ещё пуст: реестр имён
  живёт в памяти и после старта холодный. В приложении в это время могут быть
  номера вместо фамилий.
* **До 20 минут** — не проходили cron-задачи (ingest фэнтези, опросы, SLPRO).
  Расписание догонит само.
* **Первый запрос к Mini App через Funnel** может отвалиться по таймауту:
  Tailscale поднимает соединение около 15 секунд. Второй заход уже быстрый.

## Отдельно: чем это НЕ должно закончиться

06.08.2026 после перезагрузки бот поднялся наполовину: Telegram отвечал, а
фэнтези-API и фоновый цикл не стартовали **молча, без ошибки в логе**. Причина —
сеть после загрузки встаёт не мгновенно, у библиотеки Google Sheets нет
таймаута, и первый же запрос к таблице повис; весь запуск ждал его.

Это исправлено: подготовка листов ушла отдельной задачей и запуск больше не
держит. Но проверка выше на всякий случай смотрит именно порт 8081 — это самый
незаметный вид отказа: бот на кнопки отвечает, а приложение у всех мёртво.

## Ручная проверка, если нет доступа к консоли

* В Telegram: `/start` → бот отвечает меню.
* Кнопка «Фэнтези» открывает приложение и показывает пул с фамилиями.
* `/admin` → «🗄 Статистика лиг» — там видно, дошли ли последние игры.
