## A. Код (первым)

1. **[я]** `git pull` ветки + `chown` + рестарт демона:
   ```
   sudo git -C /opt/basketball-bot pull origin feature/admin-menu

   sudo systemctl restart basketball-bot
   ```
2. **[я]** Проверить журнал на ошибки: `journalctl -u basketball-bot` (последние строки —
   «Бот запущен», «Фоновый цикл запущен», без трейсбеков).

## D. Фэнтези Mini App (живой бэкенд, бесплатно, без белого IP)

Фронт и API отдаёт сам бот за Cloudflare Tunnel (GitHub Pages не нужен).

5. **[ты]** Установить cloudflared (разово):
   ```
   sudo curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -o /usr/local/bin/cloudflared
   sudo chmod +x /usr/local/bin/cloudflared
   ```
6. **[ты]** Включить туннель как сервис:
   ```
   sudo cp /opt/basketball-bot/deploy/cloudflared-fantasy.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now cloudflared-fantasy
   ```
   Проверить, что появился URL: `cat /opt/basketball-bot/data/fantasy_api_url.txt`
   (вида `https://xxxx.trycloudflare.com`).
7. **[ты]** В `/opt/basketball-bot/.env` добавить строку и сохранить:
   ```
   FANTASY_API_ENABLED=true
   ```
   (порт по умолчанию 8081; трогать не нужно).
8. **[я]** Рестарт демона (поднимет фэнтези-API):
   `sudo systemctl restart basketball-bot`, затем в журнале строка
   «Фэнтези-API поднят на 127.0.0.1:8081».
9. **[ты]** Проверка снаружи: открыть в браузере
   `<URL из файла>/health` → должно вернуть `{"ok": true}`.
10. **[ты]** В личке боту: `/fantasy` → появится кнопка «🏆 Открыть фэнтези».
    (Пока нет активного сезона — ответит «нет активного сезона».)
11. **[ты]** Запустить сезон: /admin → «🏆 Фэнтези лига» → «▶️ Старт сезона».
12. **[ты]** Открыть `/fantasy` → «Открыть фэнтези» → собрать состав (проверка
    сквозного драфта в реальном Telegram, из-под игрока команды).
